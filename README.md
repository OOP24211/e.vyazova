Проект представляет собой простую игру, выполненную с использованием библиотеки SFML.
Игрок управляет котом, который должен ловить мышей. В игре есть:

персонаж (кот),
цель (мышь),
фон игры,
ресурсы (текстуры),
обработка ввода,
анимация.

Требования для сборки:
CMake 3.16+
Компилятор C++17+
Установленная библиотека SFML 2.6+
